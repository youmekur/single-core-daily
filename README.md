# Single Core · 每日清单

iPad 每日学习与项目清单（无后端、离线优先）。

- 本科五门课程：完成才轮换，未完成保留当前科目。
- 数学、AI 理论、英语、自媒体、研发项目、今日收尾：每日按设备本地日期重置。
- 408 每 5 次本科完成学习，建议安排 2 次专题；不影响主轮换。
- 所有勾选与记录仅保存在设备浏览器的 localStorage；不上传个人内容到仓库。
- 支持 JSON 数据导出/导入，请定期备份。

## iPad 安装

打开 https://youmekur.github.io/single-core-daily/ ，在 Safari 里选择「分享 → 添加到主屏幕」。初次打开需要联网，此后支持已缓存的离线页面。

## 发布

GitHub Settings → Pages → Deploy from a branch → main / (root)。
