# Single Core · 每日清单

v1.2 · 轻量、离线优先的 iPad 学习与项目日常清单。

[打开应用](https://youmekur.github.io/single-core-daily/)

## 三个界面

- **今日执行**：本科五科按实际完成轮换，数学、AI、英语、408 弹性专题、自媒体、研发项目与今日收尾。时长记录可选，不阻塞勾选。
- **数据分析**：近 7/30/90 天及全部记录；核心 KPI、响应式每日趋势；周/月对比、课程完成率、研发项目分布、产出记录按需展开；可导出 CSV。
- **设置与数据**：JSON 备份、恢复和清空今日勾选。

## 数据兼容

- 保留 v1 原有本地存储键 `single-core-daily-checklist-v1`、数据结构和导入格式，不清空旧记录。
- 所有信息只存在设备浏览器的 `localStorage`，不自动跨设备同步。
- 学习时长只有主动录入才纳入统计；无记录日不计为任务失败。
- 本科五科完成后才进入下一门，未完成不会跳科。
- 网站资源使用 Service Worker 缓存，首次打开需要网络，之后可离线使用；重新联网时获取新版本。

## iPad 安装

使用 Safari 打开 [网页](https://youmekur.github.io/single-core-daily/)，点击「分享 → 添加到主屏幕」，选择作为网页 App 打开。

## 部署

GitHub Pages：Settings → Pages → Deploy from a branch → main / (root)。

## 验收建议

1. 390px 窄屏与 834px iPad 竖屏下，任务清单、三标签和趋势图无溢出。
2. 默认只展示今日清单；统计无完成数据时展示简洁空状态。
3. 勾选、撤销、刷新后记录持久化，本科指针仅随完成推进。
4. 每个标签可通过键盘左右方向键切换，输入框有可见标签。
5. JSON 导出/导入与 CSV 明细继续可用。
